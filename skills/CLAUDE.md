# Skill Authoring

When creating or editing any skill file (SKILL.md, Level 3 resource, or supporting doc), apply `~/.claude/rules/skill-conventions.md` — that file is the single source of truth for frontmatter, progressive disclosure, structure, language, scope buckets, invocation control, script extraction, and design qualities.

Do **not** restate any of those conventions here. This file exists only to point at the rule; keeping it thin means editing a Level 3 file does not drag ~200 lines of authoring guidance into context.
