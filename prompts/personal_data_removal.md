# Personal Data Removal

Scan the open web for your personal information, build a prioritized removal queue across data brokers and people-search sites, submit opt-out requests, and track them weekly until each record disappears.

---

Search the internet for everything about me.

Find every site selling, listing, or sharing my personal information.

Make a removal list with each website opt-out link.

Write strong removal messages that make each site delete my info.

Visit each site and submit the removal request.

Check weekly, track what changed, and keep changing removal requests until my information disappears.
